# KPI 五层框架
| 层 | 指标 | 开源工具 |
|---|---|---|
| 流量 | UV、来源、自然搜索 | Umami / Plausible, SerpBear |
| 转化 | 线索率、注册、预约 | PostHog, Cal.com |
| 留存 | 回访、邮件打开/点击 | listmonk / Mautic |
| 收入 | 付费数、CAC、LTV | 支付平台报表 |
| 内容 | 发帖数、互动率 | Postiz |
