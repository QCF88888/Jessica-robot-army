# 000 General Commander · IDEA to 90-day execution report

入口为 [report.mjs](./report.mjs) 的 generateReport。000 接收 IDEA，组织联网检索、生成 13 节报告、检查交付完整性，并将首周行动交给创始人。003 财务官复核计算与现金流；011 竞品监测复核市场证据；004 只在需要融资时接手资金缺口。上述岗位交接由控制台调度实现。

## 服务端接入

在现有网站生成方案接口的服务端处理函数内调用：

```js
const report = await generateReport({ idea, region, language }, env);
```

配置 Workers AI 绑定 AI、能支持长 JSON 输出的聊天模型 AI_MODEL，以及服务端密钥 BRAVE_SEARCH_API_KEY。搜索查询会向 Brave 发送 IDEA 摘要和地区；启用前更新页面的数据处理说明。前端按 sections 的声明顺序显示正文，把 [S编号] 关联到 research.sources，显示检索日期和 preliminary 状态。使用转义文本或经过清理的 Markdown。服务异常显示可重试错误，禁止将空白页显示为完成。此模块不部署公共接口，不保存客户输入。

## 跨境电商试算示例

输入「我想搭建一款跨境电商平台」。起步假设：先验证一条跨境线路、一个客群、一个品类；创始人确认货源地和目的地后再核算运费与税费。
Eurostat 报告 2024 年欧盟互联网用户中 77% 在前 12 个月有网购行为。此指标只支持网购行为普遍，不能据此估算某条线路或品类的销售额。
来源：https://ec.europa.eu/eurostat/en/web/products-eurostat-news/w/ddn-20250220-3

示例假设：第三方商户履约，平均订单 EUR 60，佣金率 15%，每单平台承担的支付、售后和获客分摊合计 EUR 6，则每单贡献 EUR 3。固定成本 EUR 600/月时，盈亏平衡点为 200 单/月，GMV 为 EUR 12,000，平台佣金收入为 EUR 1,800。以上均为演算输入，实际费率、退货、履约责任和税费须用报价与订单验证。

| 时间 | 负责人 | 工作与验收示例 |
|---|---|---|
| 第1–7天 | 创始人、011 | 比较三类候选商品，取得三家供应商报价，访谈十位目标买家，确定一条可核算到岸成本的线路。|
| 第8–30天 | 创始人、003 | 核对注册与收款要求、域名和品牌可用性，上线单品类网站，走通下单、发货与退款测试。|
| 第31–60天 | 创始人、运营 | 跑两个获客渠道，完成首批真实交付，逐单记录贡献、履约时间及售后成本。|
| 第61–90天 | 000、003 | 复核重复获客成本和贡献；若单笔亏损，先改运费、定价或选品；验证复购与供给稳定后再预算 App 和商户 SaaS。|

以上为工作流演示。验收时至少覆盖实物、服务和软件项目，以及搜索不可用、来源编号错误和模型漏章。
