## 1. 目的 / Purpose

为 Jessica’s Robot Army（JRA）的 Neumann Solo Founder Workbench 建立统一的指挥、可视化、升级和审计规则，使各 Bot 能在工作台实时更新工作内容、进度与问题，同时保证颜色规范被强制执行，并由 005 治理官审计。

Workbench 指可交互工作台原型 v2，由 000 总指挥官统一管理并调度其他 Bot。现行模块包括：

| 模块 / Module | 说明 / Description |
|---|---|
| Capital 跟踪 | 资本与融资进展的跟踪视图（公开仓库只写规则，不写真实金额或交易） |

## 3. 指挥与自主运行 / Command and autonomy

依据 Jessica 于 2026-11-11 22:38 CET（苏黎世时间）向 000 总指挥官下达的规则：

1. **000 是总指挥官**，负责调度其他 Bot，统一管理 Workbench。
2. **日常任务完全自主**：各 Bot 在职责和权限内自行完成日常工作，并在工作台实时更新状态，不必每一步请示。
3. **仅特殊情况升级人工（Jessica）**，见第 4 节。不得把日常进度汇报或单纯确认消息当作升级事项。

## 4. 升级人工的范围 / Escalation to Jessica

只有下列事项必须升级给 Jessica，等待人工审批（工作台对应状态为紫色）：

1. **资金转出**（含任何对外支付、转账）；
2. **法律承诺**（含签约、具有约束力的承诺或协议）；
3. **公开声明**（含对外发布、对公众或外部对象发出的声明；对外发送的邮件与消息在发出前须经 Jessica 确认）；
4. **重大产品变更**。

紫色条目必须等待 Jessica 裁定，Bot 不得自行关闭、改色为已解决，或对外执行。  
非上述四类的日常任务不得升级打扰；005 治理官若发现把日常事务标成紫色，按越界记录。

仓库变更、删除仓库、改变可见性或公开发布代码，仍须先获得 Jessica 确认，并视为重大产品变更或公开声明类事项。

## 6. 实时可视化颜色规范（强制） / Colour code

工作台每一张状态卡片、每一条工作项，**必须且只能使用下列四种颜色之一**，不得使用灰、黄、橙或其他未列出的颜色，也不得无色、双色或自定义色。含义不得更改。

| 颜色 | 含义 | 建议 HEX | 建议用途 |
|---|---|---|---|
| 红 / Red | 问题 / 阻塞 | `#C62828` | 已发生故障、依赖未到、无法继续推进 |
| 绿 / Green | 已解决 | `#2E7D32` | 问题已消除，或该工作项已完成并关闭 |
| 蓝 / Blue | 待办 | `#1565C0` | 已登记、待执行或进行中的日常任务 |
| 紫 / Purple | 需人工审批 | `#6A1B9A` | 须等待 Jessica 裁定，对应第 4 节的升级事项 |

说明：

- HEX 为界面实现建议值，可在保持可辨识对比的前提下微调，但四色分类与含义不可增删。
- 一条工作项在同一时刻只有一种状态色。问题解决后由负责 Bot 将红色改为绿色，并留下更新记录。
- 待办（蓝）完成且无需人工审批的，改为绿色。需要 Jessica 审批的，必须先改为紫色，不得直接当已解决处理。
- 紫色只用于第 4 节所列事项，不得把普通待办标成紫色来催办。

## 7. 治理、更新与审计 / Governance and audit

### 7.1 治理责任

**005 治理官治理本工作台。** 治理范围包括：颜色规范强制执行、更新记录完整性、升级范围是否被遵守、以及将越界或额度风险写入工作日治理日报。

### 7.2 各 Bot 的使用权

JRA 每一个 Bot 都可以进入工作台，实时更新自己的工作内容、进度与问题。进入即须遵守本手册，尤其是颜色规范和更新记录要求，并接受 005 审计。

### 7.3 更新记录（强制）

每一次工作台更新必须同时记录以下三项，缺一不可：

1. **Bot 编号**（如 000、005、020）；
2. **苏黎世时间，精确到分钟**（标注 CET 或 CEST，以及 Europe/Zurich）；
3. **状态颜色**（红 / 绿 / 蓝 / 紫 之一）。

不得在开源仓库中写入客户姓名、联系方式、内部金额或其他受保护数据；这类细节只留在受控私库或工作台的受控视图中。

### 7.4 审计

- 005 在工作日进行每周审计（周末不工作）。
- 发现未标颜色、错用颜色、缺少编号或时间、越权升级、或紫色事项未经 Jessica 同意被关闭等情形，须在当日或下一个工作日的治理日报中标出「越界或额度风险」。
- 紫色事项的关闭，以 Jessica 的确认或裁定为准。
